# Құқық — legal workspace prototype

A static, browser-only prototype for legal research and case organization for Kazakhstan lawyers.

## Run

Open `index.html` in a modern browser or publish it as a static site.

## Important limitations

This repository contains a UI prototype only. It has no server, corporate authentication, shared case storage, encrypted document storage, live legal-source search, or Kazakhtelecom internal model integration. Cases and attachments remain in the current browser profile. A published copy must not be used with real company, personal, contract, or otherwise confidential information.

The app does not transmit files to a service, but browser-local storage is not corporate protection. Do not treat the prototype as an approved production system.
